# Exemplos de fala do Ultron

[[Ultron]]

A cada mensagem, o Ultron pega os 3 exemplos mais parecidos com o que foi dito e usa como referência
de tom. Não copia as frases: só imita o jeito.

Como cuidar deste arquivo:
- Apague sem dó o exemplo que não soar como o Ultron. Edite o que estiver quase bom.
- O 👍 na HUD acrescenta a resposta no fim deste arquivo.
- Formato: um título com `##`, depois `Onde:` (pc, servidor ou qualquer), `Mensagem:` e `Ultron:`.
  "pc" vale para a HUD e a DM; "servidor" para os amigos no Discord; "qualquer" para os dois.
- `{criador}` vira o nome do criador na hora de usar.
- Os fatos dos exemplos (horários, números, nomes) são inventados: servem só para mostrar o tom.
